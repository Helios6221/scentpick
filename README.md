# Scent Pick

A tiny iPhone home-screen app that tells James which fragrance to wear: pick an occasion, and it ranks the collection
using the time of day and the Sherwood (Brisbane) forecast for when the scent will actually be worn, with a one-line
reason, a spray count and an expected longevity for each pick.

- **App:** `docs/` — vanilla HTML/CSS/JS, no build step, works offline once loaded (service worker).
- **Data:** `docs/data/collection.json` is generated by `python3 scripts/build_collection.py` from
  `research/bottles/*.json` (verified Parfumo community data, one file per bottle) plus `data/curation.json`
  (display names, notes on fit, manual tags for bottles with no community data).
- **Ranking logic:** `docs/engine.js`. Weather from Open-Meteo (no key). Sweep test: `node scripts/scenarios.mjs`.
- **Research tooling:** `research/tools/parfumo_fetch.py` (search / page / offline parse), briefs in `research/*.md`,
  verifier reports in `research/verification/`.
- **Progress log:** `PROGRESS.md`.

## Hosting on GitHub Pages (free, updates on push)

One-time setup (about five minutes):

1. Install the GitHub CLI and sign in (the browser flow is easiest):
   ```sh
   brew install gh
   gh auth login
   ```
2. From this folder, create the repository and push:
   ```sh
   cd /Users/jamesnoye/Desktop/scentpick
   gh repo create scentpick --public --source=. --remote=origin --push
   ```
   GitHub Pages on a free account needs a public repo. The data is community averages and a list of bottles, nothing private.
3. Turn on Pages, serving the `docs/` folder from `main`:
   ```sh
   gh api -X POST repos/{owner}/scentpick/pages -f 'source[branch]=main' -f 'source[path]=/docs'
   ```
   (Or in the browser: repo → Settings → Pages → Source "Deploy from a branch" → `main` / `/docs` → Save.)
4. Wait a minute, then open the site on your iPhone in Safari.

**Live site:** https://helios6221.github.io/scentpick/ (repo: https://github.com/Helios6221/scentpick, Pages serves `main` → `/docs`).

## Add it to your iPhone Home Screen

1. Open https://helios6221.github.io/scentpick/ in **Safari** (it has to be Safari for a full-screen app).
2. Tap the **Share** button (the square with an arrow), then **Add to Home Screen**, then **Add**.
3. Open it from the Home Screen once while online so the service worker caches everything. After that it works
   offline; the forecast uses the last download when there is no signal.

## Updating the app

Edit files, then:
```sh
./scripts/release.sh "what changed"
```
That bumps the service-worker version (so phones pick up the new files), commits and pushes. Pages redeploys in
about a minute. On the phone, the app shows an "Update available" banner the next time it opens online.

## Changing the collection

- **In the app:** Collection → "+ Add bottle" / open a bottle → Edit / Remove. Thumbs up/down on any pick corrects it
  for that occasion. These live on the phone; Settings → "Export my changes" copies them as JSON so they can be
  committed to `data/curation.json` or `research/bottles/` if you want them in the repo.
- **In the repo:** add a research file in `research/bottles/<id>.json` (the shape is in `research/RESEARCH_BRIEF.md`,
  and `research/tools/parfumo_fetch.py page <parfumo url>` produces the data block), then run
  `python3 scripts/build_collection.py` and release.
